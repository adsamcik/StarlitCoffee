# Security policy

## Reporting a vulnerability

Please do not disclose security or privacy vulnerabilities in a public issue.
Use GitHub's private vulnerability reporting for this repository when it is
available. If private reporting is unavailable, contact the repository owner
through the contact information in the published
[privacy policy](docs/privacy/index.html).

Include the affected version, reproduction steps, expected impact, and any
suggested mitigation. Avoid including real coffee-bag photos, exported user
databases, access tokens, or other personal data unless explicitly requested
through a secure channel.

## Scope

Security fixes are prioritized for the current release line. Historical builds
may not receive patches. The project does not operate an application backend;
third-party Android, GitHub Packages, barcode lookup, and optional on-device
inference components retain their own security policies.
