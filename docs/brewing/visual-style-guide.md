# Brewing illustration style guide

## Purpose

Instructional imagery teaches one physical action at a time. It supports text,
not replaces it, and must remain legible at phone size and in every locale.

## Required visual language

- Text-free, number-free, logo-free, original semi-flat instructional art.
- Physically accurate brewer geometry, filter placement, liquid level, hand
  placement, and flow direction.
- One action or state per 4:3 composition, with the action in a crop-safe center.
- Restrained warm-neutral palette, soft shadows, uncluttered neutral background,
  clear active/inactive object separation.
- Hands only when they clarify an action. No decorative kitchen scenes,
  photorealism, multi-panel recipes, or UI-like overlays.
- Safety-sensitive actions explicitly show stable support and correct heat,
  pressure, and orientation states.

## Accessibility

- Each asset has meaningful localized alt text and a concise text instruction.
- Colour alone cannot communicate a safety or state transition.
- Small liquid-level differences must be paired with precise text.

## Review checklist

1. Inspect full-size and expected phone-size rendering.
2. Verify the profile, equipment stack, and action against the evidence ledger.
3. Reject words, labels, logos, impossible physics, unsafe poses, or multiple
   actions.
4. Check light/dark presentation and crop-safe placement.
5. Record prompt revision, reviewer, and status in the asset manifest.
