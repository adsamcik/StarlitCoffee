# Pulsar iteration 3 of 5

This pass follows [v11](../method-icon-concept-v11/README.md). After reviewing
that render, Astra recommended deepening the continuous base band. Root lowered
the opening roofs and their rounded corners by 0.3 units, retaining widths,
shoulders and the common foot baseline. The band occupies about 56 percent
of the base height, closer to the manufacturer front photo.

`revision.json` records the geometry change. `preview.png` and
`iteration-comparison.png` are SVG renders with physical-pixel size samples.
The Android XML is a study export. The applied fifth pass and full comparison
are in [v14](../method-icon-concept-v14/README.md).
