# Method icon concepts after rejected geometric redraws

Preview only. The app uses its restored original method icons. These images
were generated with the built-in image generator on 2026-10-02 and have not
been accepted as replacement artwork.

`astra-style-board.png` (prompt in `astra-prompt.txt`) is Astra's softer two-icon concept based on the original
Brewing sets screenshot. It preserves the original character but remains too
close to the old shapes to resolve the equipment-likeness problem.

`pulsar-photo-concept.png` follows that softer style direction and uses the
[manufacturer's Pulsar photo](https://nextlevelbrewer.com/shop/nextlevel-pulsar-brewer/)
as a separate shape reference. It shows a compact clear chamber, shallow cap,
substantial rounded valve base, short supports and a front valve detail. The
reference photo is a temporary build input and is not committed here.

The exact prompt for the photo-based sample is in `pulsar-prompt.txt`. This is
an image-generation concept, not proof of Android rendering or vector fidelity.
